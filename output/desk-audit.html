Found during the audit and fixed the same day

These were not on any list. They surfaced from reading the code the way an outside quant would, and each one would have hurt the record.

  • No in-season data path existed.The season list was hard-coded to 2021–25 and the board was always built in offseason mode. The model would have stayed on last season's history, the market-role baseline, and half-strength form all year — none of the validated in-season edges (recency, xTD's +2–3% Brier, the injury report) would ever have switched on. Built refresh_data.py and a mode switch; the board now prints OFFSEASON or IN-SEASON, and xTD enters its in-season mode from Week 4, where it was validated. Smoke-tested on 2025 data.
  • No grading loop.Work order 2, flagged repeatedly as the biggest missing foundation. Built the ledger (every number frozen at open, latest, and close) and the grader (win / loss / push / void, units at price, CLV in points, separate records per lane, calibration by grade and by model probability over the whole pool, a running record file). Settlement math is unit-tested; the stats path is verified against nflverse 2025. Week 1 is the first live test.
  • The Games tab was stale.Rows from September 1 were carried forward on every run with no game labels — Arizona +440 at FanDuel was long gone. Rebuilt live each run and relabeled as market intel: a bettable book off Pinnacle by a point or more. We have no validated edge on sides (ratings run ~50% ATS; a book being off does not predict the move), so nothing here goes on the Card.
  • A fresh clone could not build the board.Every data table the run reads was gitignored. The twenty it needs (~10 MB) are committed now.
  • Props re-pricing cost API credits.Fetch is now split from pricing for props, as it already was for touchdowns; a model change re-prices the cached lines for free.
  • Your name won."TD Stack" is the Touchdown Tax everywhere.

Deepen · simplify · remove

Deepen, in this order

  1. Run the loop. Week 1 grades Monday. After three weeks: re-earn the intel weight, the cascade, the grade bands; check the early-season TD top bucket (an open finding: our .45–.55 predictions hit ~62% in weeks 1–3 historically).
  2. Kicker lane. Your favorite, and books under-model it: team field-goal-range drive rate × distance make-rate × the kicker. About a day; earn it before it ships.
  3. Execution-book view. DK / FanDuel / BetMGM price beside best-anywhere; the ledger records both.
  4. Weather forecast source. Open-Meteo is free; it finally activates the validated weather module in the Sunday pass.
  5. Rookies and no-history players on the market-role baseline in weeks 0–3, so beat intel or an injury can still surface one. Today they are silently REVIEW.
  6. Pace and pass-rate for yardage volume, done the multi-factor way.

Simplify or remove

  • Archive the September-1 modules that are no longer in the run (whale missile, ML/futures board, smash spots, usage layer, enrich, model update, the ratings engine, cards, context bundle, desk card, verify, fantasy). The live tree should be ~25 modules, not 50; the dead ones confuse future sessions and the research bot. Mechanical — a session where you can eyeball the list.
  • The model registry and the v1 research log become archives, not truth.
  • The pooled TD model can retire after Week 5 if the blend weight stays at .85 in-season.
  • The games lane stays only as CLV content for the brand; if it clutters, drop it.
  • The primetime SGP is lotto content with honest limits (no DK quote feed, two calibration slips) — never sold as edge.

Risks I would name to the owner

  1. The push. Nothing scheduled works on the new model until the bundle is on GitHub.
  2. Week 1 is the weakest week by construction — offseason mode, median edge ~3%. Expect the Card to run 52–56% early, not 60%; weeks 1–3 are for the record and the CLV read.
  3. The in-season paths were never exercised on live 2026 data. Smoke-tested on 2025; the Week 2 Tuesday email's "mode:" line is the first real check.
  4. The 2026 injury loader has not seen a real report yet.
  5. Beat intel is a web search per player run by a scheduled agent — variable quality. Only the hard gates should be trusted blind.
